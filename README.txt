HALO CE PLAYTEST
================

Setup
-----
1. Extract this entire folder somewhere permanent. Do not move individual files out of it.
2. Double-click "Install Halo CE Playtest.cmd".
3. Launch the new "Halo CE Playtest" desktop shortcut.

Game data
---------
This package does not include copyrighted Halo game data.

On first launch, select your own legitimate Halo Xbox disc image when the game asks for it.
The game will extract the required maps beside halo.exe. You can instead place an already
extracted complete "maps" folder beside halo.exe; it must include ui.map.

Windows security
----------------
halo.exe is an unsigned community playtest build. Windows Smart App Control or an
organization's application-control policy may block it. Do not disable system security to
run it; use a trusted signing route or an approved development computer if it is blocked.

Keep together
-------------
- halo.exe
- SDL3.dll
- config.toml
- Play Halo CE Playtest.cmd
- Install Halo CE Playtest.cmd

This is a portable release build for x64 Windows PCs. Save files use the normal per-user
Halo save location, so each Windows account keeps its own saves.
